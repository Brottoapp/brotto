# Brotto

**A mesada que cresce** — protótipo do app de mesada e educação financeira para famílias, baseado no método 5D do livro *O Poder da Mesada*. Bilíngue PT/DE, fiel à API bancária do Treezor.

O app é um único arquivo autocontido: [`index.html`](index.html). Abra no navegador ou instale no celular (PWA embutido: manifesto + ícones já no arquivo).

## Site
https://brotto.app

## Estrutura
- `index.html` — o app completo (HTML/CSS/JS, arquivo único)
- `CNAME` — domínio do GitHub Pages

## Rodar localmente
Abra o `index.html` em qualquer navegador. Não precisa de build nem servidor.
